## **Carnival Wheel**

每次测试时间限制：1 秒

每次测试内存限制：256 兆字节

你有一个奖品转盘，被分为 $l$ 个扇区，编号从 $0$ 到 $l-1$。这些扇区排列成一个圆圈，因此在扇区 $l-1$ 之后，编号又从扇区 $0$ 开始。

最初，奖品指针位于扇区 $a$。每次你旋转转盘，指针会精确地向前移动 $b$ 个扇区。也就是说，旋转一次后，指针从扇区 $a$ 移动到扇区 $(a+b) \bmod l$；旋转两次后移动到 $(a+2b) \bmod l$，依此类推$^*$。

你可以旋转转盘任意次数（包括零次）。在你停止旋转后，指针最终停留的扇区决定了你的奖品：你将获得等同于该扇区编号的金额。

请问你能获得的**最大奖品**是多少？

$^*$ 这里，$x \bmod y$ 表示 $x$ 除以 $y$ 的余数。

### **输入 (Input)**

每个测试包含多个测试用例。第一行包含测试用例的数量 $t$ ($1 \le t \le 500$)。接下来是测试用例的描述。

每个测试用例只有一行，包含三个整数 $l, a$ 和 $b$ ($1 \le l, b \le 5000, 0 \le a \le l-1$)。

### **输出 (Output)**

对于每个测试用例，输出能够获得的最大奖品金额。

### **样例 (Example)**

**Input**

Plaintext

```
4
5 3 2
2 0 6
8 2 4
100 0 1
```

**Output**

Plaintext

```
4
0
6
99
```

### **提示 (Note)**

- **第一个测试用例**：通过旋转转盘三次然后领取奖品，你可以获得最大值 $4$。指针位置的序列为：$3, 0, 2, 4, 1, 3, 0, \dots$
- **第二个测试用例**：指针将无限期地停留在扇区 $0$。
- **第四个测试用例**：当 $b=1$ 且从扇区 $0$ 开始时，指针将遍历所有扇区，包括最后一个。









































## 解题思路

**直觉层面**

- 找到**本质步长** ： 多次绕圈的落点与起始点间的**最小偏移量**
- 观察发现是 **gcd(b, l)**

**数学层面**

- x = (a + b * k) mod l        //设x为能抵达的最大值
- x = a + b * k - y * l
- 根据**裴蜀定理** b * k - y * l 的最小值是gcd(b, l)
- $x \equiv a \pmod{\gcd(b, l)}$

## 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {
        int l, a, b;
        cin >> l >> a >> b;

        int g = gcd(l, b);
        cout << l - g + (a % g) << '\n';  //a mod g < g确保了答案绝对不会超过边界
    }
    return 0;
}
```
