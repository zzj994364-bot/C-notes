## 代码炸了的经典问题来源

**常见**：

- 少写了**cin**
- **数组溢出**，检查数组大小
- **resize无法重置元素**，assign可以重置元素
- 递归**死循环**

- BFS中next_node未记录父节点信息

- **字符 '1' **转整数 '1' 没有 **- '0'**

#### 1. 数组越界访问

**问题描述**：访问数组时索引超出有效范围，导致未定义行为。

**具体例子**：

```cpp
int arr[5] = {1, 2, 3, 4, 5};
cout << arr[5] << endl;  // 越界！有效索引是 0-4
```

**解决方法**：

- 使用 `vector` 并用 `.at()` 方法（会抛出异常）
- 始终检查索引范围：`if (i >= 0 && i < arr.size())`
- 使用循环时确保条件正确：`for (int i = 0; i < n; i++)`

#### 2. 空指针/空迭代器解引用

**问题描述**：对空指针或无效迭代器进行解引用操作。

**具体例子**：

```cpp
vector<int> v;
auto it = v.end();  // end() 指向尾后位置
cout << *it << endl;  // 炸了！不能解引用 end()

int* ptr = nullptr;
cout << *ptr << endl;  // 炸了！空指针解引用
```

**解决方法**：

- 使用前检查：`if (ptr != nullptr)` 或 `if (it != v.end())`
- 使用 `empty()` 检查容器：`if (!v.empty())`
- 访问容器元素前确保存在：`if (map.count(key))`

#### 3. 迭代器失效

**问题描述**：容器修改后继续使用旧迭代器。

**具体例子**：

```cpp
vector<int> v = {1, 2, 3, 4, 5};
for (auto it = v.begin(); it != v.end(); it++) {
    if (*it == 3) {
        v.erase(it);  // 炸了！erase 后 it 失效
    }
}
```

**解决方法**：

```cpp
// 正确做法：使用 erase 的返回值
for (auto it = v.begin(); it != v.end(); ) {
    if (*it == 3) {
        it = v.erase(it);  // erase 返回下一个有效迭代器
    } else {
        it++;
    }
}
```

#### 4. 整数溢出

**问题描述**：运算结果超出数据类型表示范围。

**具体例子**：

```cpp
int a = 2000000000;
int b = 2000000000;
int sum = a + b;  // 炸了！超出 int 范围(-2^31 ~ 2^31-1)
cout << sum << endl;  // 输出负数或错误值
```

**解决方法**：

```cpp
// 方法1：使用更大的数据类型
long long sum = (long long)a + b;

// 方法2：检查溢出
if (a > INT_MAX - b) {
    // 处理溢出情况
}
```

#### 5. 除零错误

**问题描述**：除数为零导致程序崩溃。

**具体例子**：

```cpp
int a = 10;
int b = 0;
int result = a / b;  // 炸了！除以零
```

**解决方法**：

```cpp
if (b != 0) {
    int result = a / b;
} else {
    // 处理除零情况
    cerr << "除数不能为零" << endl;
}
```

#### 6. 栈溢出（递归过深/大数组）

**问题描述**：递归层数过多或栈上分配过大数组。

**具体例子**：

```cpp
// 例子1：无限递归
void func() {
    func();  // 炸了！没有终止条件
}

// 例子2：栈上大数组
void process() {
    int arr[10000000];  // 炸了！栈空间不足
}
```

**解决方法**：

```cpp
// 方法1：添加递归终止条件
void func(int depth) {
    if (depth > 1000) return;
    func(depth + 1);
}

// 方法2：使用堆分配
vector<int> arr(10000000);  // 或 int* arr = new int[10000000];
```

#### 7. 修改常量或只读内存

**问题描述**：尝试修改字符串字面量或 const 对象。

**具体例子**：

```cpp
char* str = "Hello";
str[0] = 'h';  // 炸了！字符串字面量在只读区

const int x = 10;
int* ptr = (int*)&x;
*ptr = 20;  // 炸了！修改 const 对象（未定义行为）
```

**解决方法**：

```cpp
// 使用可修改的数组
char str[] = "Hello";
str[0] = 'h';  // 正确

// 或使用 string
string str = "Hello";
str[0] = 'h';  // 正确
```

#### 8. 容器使用错误导致的问题

**问题描述**：对空容器调用 `front()`、`back()`、`top()` 等。

**具体例子**：

```cpp
vector<int> v;
cout << v.front() << endl;  // 炸了！空 vector

stack<int> s;
cout << s.top() << endl;  // 炸了！空 stack

queue<int> q;
q.pop();  // 炸了！空 queue
```

**解决方法**：

```cpp
if (!v.empty()) {
    cout << v.front() << endl;
}

if (!s.empty()) {
    cout << s.top() << endl;
}

if (!q.empty()) {
    q.pop();
}
```

#### 9. map/set 使用 [] 访问不存在的键

**问题描述**：`map[key]` 会自动创建不存在的键，可能导致逻辑错误。

**具体例子**：

```cpp
map<string, int> m;
if (m["key"] == 0) {  // 即使 key 不存在，也会被创建并初始化为 0
    cout << "不存在" << endl;
}
cout << m.size() << endl;  // 输出 1，而非 0
```

**解决方法**：

```cpp
// 方法1：使用 count() 或 find()
if (m.count("key") == 0) {
    cout << "不存在" << endl;
}

// 方法2：使用 find()
auto it = m.find("key");
if (it != m.end()) {
    cout << it->second << endl;
}

// 方法3：使用 at()（会抛出异常）
try {
    int val = m.at("key");
} catch (out_of_range& e) {
    cout << "键不存在" << endl;
}
```

#### 10. 优先队列/set/map 的比较函数错误

**问题描述**：自定义比较函数不满足严格弱序关系。

**具体例子**：

```cpp
struct Cmp {
    bool operator()(int a, int b) {
        return a <= b;  // 炸了！应该用 < 而非 <=
    }
};
priority_queue<int, vector<int>, Cmp> pq;
```

**解决方法**：

```cpp
// 正确的比较函数（严格弱序）
struct Cmp {
    bool operator()(int a, int b) {
        return a < b;  // 使用严格小于
    }
};
```

#### 11. 字符串越界或未初始化

**问题描述**：访问 string 越界位置或使用未初始化的 char 数组。

**具体例子**：

```cpp
string s = "abc";
cout << s[5] << endl;  // 越界但可能不崩溃（未定义行为）

char str[10];
cout << str << endl;  // 炸了！未初始化，包含垃圾值
```

**解决方法**：

```cpp
// 方法1：检查范围
if (idx < s.size()) {
    cout << s[idx] << endl;
}

// 方法2：初始化数组
char str[10] = {0};  // 或 memset(str, 0, sizeof(str));

// 方法3：使用 string
string str = "";  // 自动初始化为空
```

#### 12. 循环中修改循环变量导致的问题

**问题描述**：在基于范围的 for 循环中修改容器大小。

**具体例子**：

```cpp
vector<int> v = {1, 2, 3, 4, 5};
for (int x : v) {
    v.push_back(x * 2);  // 炸了！循环中修改容器大小
}
```

**解决方法**：

```cpp
// 方法1：先拷贝
vector<int> v = {1, 2, 3, 4, 5};
vector<int> temp = v;
for (int x : temp) {
    v.push_back(x * 2);
}

// 方法2：使用索引（确保只遍历原始元素）
int n = v.size();
for (int i = 0; i < n; i++) {
    v.push_back(v[i] * 2);
}
```

#### 13. 忘记初始化变量

**问题描述**：局部变量未初始化就使用，包含随机值。

**具体例子**：

```cpp
int sum;  // 未初始化
for (int i = 0; i < 10; i++) {
    sum += i;  // 炸了！sum 包含垃圾值
}
```

**解决方法**：

```cpp
int sum = 0;  // 初始化为 0
for (int i = 0; i < 10; i++) {
    sum += i;
}
```
