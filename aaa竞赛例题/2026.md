## **C - 2026** ![img](https://img.atcoder.jp/assets/top/img/flag-lang/ja.png) / ![img](https://img.atcoder.jp/assets/top/img/flag-lang/en.png)

------

Time Limit: 2 sec / Memory Limit: 1024 MiB

Score : 300 points

### Problem Statement

A positive integer *n* is called a **good integer** when it satisfies the following condition:

- There exists exactly one pair of integers (*x*,*y*) that satisfies 0<*x*<*y* and *x*2+*y*2=*n*.

For example, when *n*=2026, it can be verified that (*x*,*y*)=(1,45) is the only pair of integers that satisfies 0<*x*<*y* and *x*2+*y*2=*n*. Thus, 2026 is a good integer.

You are given a positive integer *N*. Enumerate all good integers not exceeding *N*.

### Constraints

- 1≤*N*≤107
- *N* is an integer.

------

### Input

The input is given from Standard Input in the following format:

```
N
```

### Output

Let there be *k* good integers not exceeding *N*, and let (*a*1,*a*2,…,*a**k*) be the sequence of these integers in ascending order. Output the answer in the following format. (If *k*=0, output the second line as an empty line.)

```
k
a1 a2 … ak
```

------

## 解题思路

**思考**

- good integer的合法x，y只有**一对**
- x，y不相同
- 在结果小于n的限制下枚举x，y 若得出的结果重复出现两次及以上则不是good integer

**实现难点**

- 使用**数组**而非set来统计计算结果避免超时

## 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int num[10000005];
int main() {
    int n;
    cin >> n;

    for (long long x  = 2; x < sqrt(n); x++) {
        for (long long y = 1; y < x; y++) {
            long long temp = x * x + y * y;
            if (temp <= n) num[temp]++;
        }
    }


    set<long long> ans;
    for (int i = 0; i <= n; i++) {
        if (num[i] == 1) ans.insert(i);
    }

    cout << ans.size() << '\n';
    for (auto x : ans) cout << x << ' ';
    return 0;
}
```
