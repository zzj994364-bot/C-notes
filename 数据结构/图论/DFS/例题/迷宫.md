## 迷宫
 时间限制：每个测试 2 秒
 内存限制：每个测试 256 MB

Pavel 喜欢网格迷宫。一个网格迷宫是一个 $n \times m$ 的矩形迷宫，每个格子要么是空的，要么是墙。你只能从一个格子移动到另一个格子，当且仅当两个格子都是空的并且有公共边。

Pavel 画了一个网格迷宫，所有空格子形成了一个连通区域。也就是说，你可以从任意一个空格子走到任何其他空格子。Pavel 不喜欢迷宫里的墙太少。他希望把 **恰好 k 个空格子变成墙**，同时保持剩下的空格子仍然是连通的区域。帮他实现这个目标。

**输入**
 第一行包含三个整数 $n, m, k$ （$1 \le n, m \le 500, 0 \le k < s$），其中 $n$ 和 $m$ 分别表示迷宫的高度和宽度，$k$ 是 Pavel 想要增加的墙的数量，$s$ 表示原始迷宫中空格子的数量。

接下来的 $n$ 行，每行 $m$ 个字符，描述原始迷宫。如果某个字符是 "."，则对应格子为空；如果字符是 "#"，则对应格子为墙。

**输出**
 打印 $n$ 行，每行 $m$ 个字符，表示修改后的迷宫。将被改造成墙的空格子标记为 "X"，其他格子保持不变（即 "." 和 "#" 不变）。

保证至少存在一种解。如果存在多种解，可以输出任意一种。

**示例**

输入：

```
3 4 2
#..#
..#.
#...
```

输出：

```
#.X#
X.#.
#...
```

输入：

```
5 4 5
#...
#.#.
.#..
...#
.#.#
```

输出：

```
#XXX
#X#.
X#..
...#
.#.#
```



































## 解题思路

**核心思想**

- 构造图，（利用二维adj）
- 想象一个以任意点为root的tree
- 从root出发依次push进一个**stack**记录剥离顺序

**流程难点**

- 构造迷宫时的初始化:

  ```cpp
  vector<vector<int>> maze;
  maze.resize(n + 2, vector<int>(m + 2, '#'));
  //n + 1能确保1-based
  //n + 2能设置外围一圈“哨兵”，防止检查上下左右邻居的时候溢出
  ```

## 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

//adj
const int MAXN = 505;
vector<vector<vector<pair<int, int>>>> adj(MAXN, vector<vector<pair<int, int>>>(MAXN));
vector<vector<bool>> visited(MAXN, vector<bool>(MAXN, false));
//maze
vector<vector<char>> maze;

//dfs
stack<pair<int, int>> stage;
void dfs(int x, int y) {
    visited[x][y] = true;
    stage.push({x, y});
    for (auto next : adj[x][y]) {
        if (!visited[next.first][next.second]) {
            dfs(next.first, next.second);
        }
    }
}

int main() {
    int n, m, k;
    cin >> n >> m >> k;
    maze.resize(n + 2, vector<char>(m + 2, '#'));
    bool first_valid_found = false;
    pair<int, int> first_valid;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            char c;
            cin >> c;
            if (!first_valid_found && c == '.') {
                first_valid_found = true;
                first_valid = {i, j};
            }
            maze[i][j] = c;
        }
    }
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (maze[i][j] == '#') continue;
            //up
            if (maze[i][j - 1] == '.') adj[i][j].push_back({i, j - 1});
            //down
            if (maze[i][j + 1] == '.') adj[i][j].push_back({i, j + 1});
            //left
            if (maze[i - 1][j] == '.') adj[i][j].push_back({i - 1, j});
            //right
            if (maze[i + 1][j] == '.') adj[i][j].push_back({i + 1, j});
        }
    }

    dfs(first_valid.first, first_valid.second);

    for (int i = 1; i <= k; i++) {
        maze[stage.top().first][stage.top().second] = 'X';
        stage.pop();
    }

    //output
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            cout << maze[i][j];
        }
        cout << '\n';
    }

    return 0;
}
```
