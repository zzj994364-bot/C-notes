## Counting Rooms
- **Time limit:** 1.00 s
- **Memory limit:** 512 MB

You are given a map of a building, and your task is to count the number of its rooms. The size of the map is $n \times m$ squares, and each square is either floor or wall. You can walk left, right, up, and down through the floor squares.

### Input

The first input line has two integers $n$ and $m$: the height and width of the map.

Then there are $n$ lines of $m$ characters describing the map. Each character is either `.` (floor) or `#` (wall).

### Output

Print one integer: the number of rooms.

### Constraints

- $1 \le n,m \le 1000$

### Example

Input:

```
5 8
########
#..#...#
####.#.#
#..#...#
########
```

Output:

```
3
```











































## 解题思路

- 用二维vector构建这个map
- 用二维vector构建visited
- 求连通块数量
  - **DFS**一个**!visited**的  **'.'**
  - 通过DFS将位于同一个连通块的其他 **'.'** 标记为 **visited**
  - 连通块数量++

## 代码实现

```cpp
//问有几个连通块
//上下左右四个方向
//通过visited标记来区分各个连通块
/* ============================================================
   二维vector记录地图
   遍历map, if (!visited) dfs, ans++
   ============================================================ */
#include <iostream>
#include <vector>
using namespace std;

//map
vector<vector<char>> grid;
//visited
vector<vector<bool>> visited;

//标记同一连通块下的vertices
void dfs(int i, int j, int n, int m) {
    visited[i][j] = true;

    if (i - 1 >= 0 && grid[i - 1][j] == '.' && !visited[i - 1][j]) 
        dfs(i - 1, j, n, m);
    if (i + 1 <= n - 1 && grid[i + 1][j] == '.' && !visited[i + 1][j]) 
        dfs(i + 1, j, n, m);
    if (j + 1 <= m - 1 && grid[i][j + 1] == '.' && !visited[i][j + 1]) 
        dfs(i, j + 1, n, m);
    if (j - 1 >= 0 && grid[i][j - 1] == '.' && !visited[i][j - 1]) 
        dfs(i, j -1, n, m);
    
}

int main() {
    int n, m;
    cin >> n >> m;

    //initialize
    grid.resize(n, vector<char>(m));
    visited.resize(n, vector<bool>(m, false));

    //read grid
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> grid[i][j];
        }
    }

    //traversal
    int ans = 0;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (grid[i][j] == '.' && !visited[i][j]) {
                dfs(i, j, n, m);
                ans++;
            }
        }
    }

    cout << ans << endl;

    return 0;
}
```
