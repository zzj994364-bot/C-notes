## 变为 0

每次测试的时间限制：2.0 秒

内存限制：256 兆字节

假设你有一个整数 $v$。在一次操作中，你可以：

- 要么设置 $v = (v + 1) \bmod 32768$
- 要么设置 $v = (2 \cdot v) \bmod 32768$

给你 $n$ 个整数 $a_1, a_2, \dots, a_n$。要使每个 $a_i$ 等于 $0$，所需的最小操作次数是多少？

### 输入

第一行包含一个整数 $n$ ($1 \le n \le 32768$) —— 整数的个数。

第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$ ($0 \le a_i < 32768$)。

### 输出

打印 $n$ 个整数。第 $i$ 个整数应等于将 $a_i$ 变为 $0$ 所需的最小操作次数。

### 样例

**输入**

```
4
19 32764 10240 49
```

**输出**

```
14 4 4 15 
```

### 注释

让我们考虑每个 $a_i$：

- $a_1 = 19$。你可以先将其加 1 得到 $20$，然后将其乘以 2 共 $13$ 次。你将在 $1 + 13 = 14$ 步内得到 $0$。
- $a_2 = 32764$。你可以将其加 1 共 $4$ 次：$32764 \to 32765 \to 32766 \to 32767 \to 0$。
- $a_3 = 10240$。你可以将其乘以 2 共 $4$ 次：$10240 \to 20480 \to 8192 \to 16384 \to 0$。
- $a_4 = 49$。你可以将其乘以 2 共 $15$ 次。





































## 解题思路

**关键观察**

- 32768 = 2^15
- 二进制中，位数大的数能**被位数小或相等的数整除**

**思路**

- 总步数 <= 15
- 分为加法步骤和乘法步骤
- 枚举加法步骤，范围：0 ~ 15

**实现难点**

- 统计**二进制末尾连续0**的个数
  - 与十进制处理方法类似：**while (n % 2 == 0 && n > 0)**,这里将**% 10**替换成了**% 2**

## 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MOD = 32768;
int main() {
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        //枚举15次内的加法操作
        
        int steps = 0;
        int ans = 15;
        for (int j = 0; j <= 15; j++) {
            int v = (n + j) % MOD;
            if (v == 0) {
                steps = j;
            } else {
                //找末尾的0个数
                int temp = v;
                int m = 0;
                while (temp % 2 == 0 && temp > 0) {
                    m++;
                    temp /= 2;
                }
                steps = j + 15 - m;
            }
            ans = min(ans, steps);
        }

        cout << ans << ' ';
    }

    return 0;
}
```
