# 状态空间搜索

**思考**

- 将数字初始状态和目标状态看作**顶点**
- 将转移条件看作**边**
- 建立**图**并进行广度优先搜索

**TIP**

- **q**中储存各个**状态**，第一个入队的是**初始状态**
- 边界检查：找到**状态的边界**并在入队阶段进行检查
- 标记以访问：通常用**dist[n] =  -1**表示未访问节点 

## 问题描述

给定两个整数 `n` 和 `m`，通过以下两种操作将 `n` 转换为 `m`：

1. **减1**：`n → n - 1`
2. **乘2**：`n → n × 2`

求最少需要多少步操作。

### 状态空间建模

#### 三要素

| 要素         | 说明         |
| ------------ | ------------ |
| **状态**     | 当前的数字值 |
| **初始状态** | 数字 `n`     |
| **目标状态** | 数字 `m`     |
| **状态转移** | 减1 或 乘2   |

#### 搜索策略

使用 **BFS（广度优先搜索）**，因为：

- 逐层扩展，保证找到的第一个解就是最短路径
- 适合求最少步数问题

### 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 20001;

int main() {
    int n, m;
    cin >> n >> m;

    // BFS 状态空间搜索
    queue<int> q;
    q.push(n);  // 初始状态入队
    
    vector<int> dist(MAXN, -1);  // 距离数组，-1表示未访问
    dist[n] = 0;  // 初始状态距离为0
    
    while (!q.empty()) {
        int cur = q.front();
        q.pop();

        // 到达目标状态
        if (cur == m) {
            cout << dist[cur] << endl;
            return 0;
        }

        // 操作1：减1
        int next_min = cur - 1;
        if (next_min > 0 && dist[next_min] == -1) {
            q.push(next_min);
            dist[next_min] = dist[cur] + 1;
        }
        
        // 操作2：乘2
        int next_mul = cur * 2;
        if (next_mul < MAXN && dist[next_mul] == -1) {
            q.push(next_mul);
            dist[next_mul] = dist[cur] + 1;
        }
    }

    cout << -1 << endl;  // 无解
    return 0;
}
```

## 核心思想解析

### 1. 队列（Queue）

```cpp
queue<int> q;
q.push(n);  // 初始状态
```

- 存储待探索的状态
- 先进先出，保证按层次扩展

### 2. 距离数组（Distance Array）

```cpp
vector<int> dist(MAXN, -1);
dist[n] = 0;
```

- **作用双重**：
  1. 记录从起点到当前状态的步数
  2. 标记状态是否已访问（-1 = 未访问）

### 3. 状态转移

```cpp
// 生成新状态
int next_min = cur - 1;
int next_mul = cur * 2;

// 检查合法性 + 未访问
if (next_min > 0 && dist[next_min] == -1) {
    q.push(next_min);
    dist[next_min] = dist[cur] + 1;  // 更新距离
}
```

### 4. 剪枝条件

- `next_min > 0`：数字不能为负
- `next_mul < MAXN`：防止数组越界
- `dist[next] == -1`：避免重复访问

## BFS 执行过程示例

假设 `n = 3, m = 10`：

```
层次0: [3]  距离=0
层次1: [2, 6]  距离=1
层次2: [1, 4, 5, 12]  距离=2
层次3: [0, 2, 8, 10, ...]  距离=3
找到目标 10，答案 = 3
```

**路径**：3 → 6 → 12 → 10（乘2 → 乘2 → 减1）

## 时间复杂度分析

- **时间复杂度**：O(MAXN)
  - 每个状态最多访问一次
- **空间复杂度**：O(MAXN)
  - 队列 + 距离数组

## BFS 模板总结

```cpp
// BFS 状态空间搜索模板
queue<State> q;
set<State> visited;  // 或使用数组标记
?
q.push(start_state);
visited.insert(start_state);

while (!q.empty()) {
    State cur = q.front();
    q.pop();
    
    if (cur == goal_state) {
        // 找到解
        return;
    }
    
    // 遍历所有可能的下一状态
    for (State next : getNextStates(cur)) {
        if (!visited.count(next) && isValid(next)) {
            visited.insert(next);
            q.push(next);
        }
    }
}
```

## 关键要点

1. ✅ **BFS 保证最短路径**：第一次到达目标就是最优解
2. ✅ **访问标记很重要**：防止重复访问，避免死循环
3. ✅ **边界检查**：防止状态超出合法范围
4. ✅ **距离记录**：用于输出答案和标记访问状态

## 扩展应用

这个模板可以应用到：

- 八数码问题

- 网络爬虫
- 任何需要找"最少步数"的问题
