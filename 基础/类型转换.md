# 类型转换

## 1. 字母大小写转换

### 函数转换

使用标准库函数 `<cctype>` 进行转换：

| 函数名    | 用途           |
| --------- | -------------- |
| islower() | 小写  ->  true |
| isupper() | 大写  ->  true |
| tolower() | 转化为小写     |
| toupper() | 转化为大写     |

```cpp
#include <iostream>
#include <cctype>
using namespace std;

int main() {
    //判断大小写
    islower(c);
    isupper(c);

    char lower = 'a';
    char upper = 'A';
    // 小写转大写
    char result1 = toupper(lower);  // 'A'
    // 大写转小写
    char result2 = tolower(upper);  // 'a'
    
    
    return 0;
}
```

**特点**：
- 安全可靠，自动处理非字母字符
- 如果输入不是字母，返回原字符
- 推荐使用

### 数字索引转换（ASCII码运算）

利用ASCII码表中大小写字母的位置关系：

```cpp
#include <iostream>
using namespace std;

int main() {
    //c = c - 'a' + 'A'; // 小写 → 大写：先算索引，再映射到大写区间
    //c = c - 'A' + 'a'; // 大写 → 小写：同理
    
    char c = 'b';
    if ('a' <= c && c <= 'z') //判断小写
        c = c - 'a' + 'A';  // 'B'
    else if ('A' <= c && c <= 'Z') //判断大写
        c = c - 'A' + 'a';  // 'b'
    
    return 0;
}
```

**原理**：
- 'A' = 65, 'Z' = 90
- 'a' = 97, 'z' = 122
- 差值固定为 32

**注意**：使用前需要检查是否为字母！

```cpp
// 安全的方式
if (c >= 'a' && c <= 'z') {
    c = c - 32;  // 小写转大写
}

if (c >= 'A' && c <= 'Z') {
    c = c + 32;  // 大写转小写
}
```

## 2. 字符与数字转换

### 字符转数字

**减去 '0'**

```cpp
char c = '5';
int num = c - '0';  // num = 5
```

**原理**：

- '0' 的 ASCII 码是 48
- '1' 的 ASCII 码是 49
- '5' - '0' = 53 - 48 = 5

### 数字转字符

**加上 '0'**

```cpp
int num = 3;
char c = num + '0';  // c = '3'
```

## 3. 字符串与数字转换

### 字符串转数字

**C++风格函数**

| 函数 | 头文件 | 功能 | 示例 |
|------|--------|------|------|
| `stoi()` | `<string>` | 字符串转int | `stoi("123")` → 123 |
| `stol()` | `<string>` | 字符串转long | `stol("123456")` → 123456L |
| `stof()` | `<string>` | 字符串转float | `stof("3.14")` → 3.14f |
| `stod()` | `<string>` | 字符串转double | `stod("2.718")` → 2.718 |

**示例代码**：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // C++风格: stoi (推荐)
    string str1 = "456";
    int num1 = stoi(str1);
    
    // C++风格: stod
    string str2 = "2.718";
    double num2 = stod(str2);
       
    return 0;
}
```

### 数字转字符串

**to_string()**

```cpp
#include <string>
using namespace std;

// to_string()
int num = 123;
string str = to_string(num);

double pi = 3.14;
string str2 = to_string(pi);
```

## 4. 强制类型转换

### C风格基本语法

```cpp
(目标类型)变量
```

### 常见的强制类型转换

#### 整型之间的转换

```cpp
int i = 100;

long l2 = (long)i;
short s2 = (short)i;
```

#### 字符与整型转换

```cpp
char c = 'b';

int num = c;        // 隐式转换（推荐）
int num = (int)c;  // 显式强转（合法，但多余）

//num  =  98 (ASCII 编码)
```
