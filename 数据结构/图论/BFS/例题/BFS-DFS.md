## **BFS-DFS**

时限：1000ms | 内存：128MB

题目描述：

给定一个包含 $N$ 个节点的图，起始节点均为 1。已知该图在进行 BFS 和 DFS 遍历时访问节点的顺序（两个排列）。你需要构造出一个满足这两个序列的简单、无向且连通的图，并输出其边集。

**算法规则说明：**

- **存储方式：** 使用邻接表。当读取一条边 $(a, b)$ 时，$a$ 被添加到 $b$ 的列表中，$b$ 被添加到 $a$ 的列表中。
- **BFS 过程：** 使用队列。将起始点入队。当队列不为空时，弹出队首节点，**按邻接表中存储的顺序**遍历其邻居，若邻居未访问则入队。
- **DFS 过程：** 递归实现。从起始点开始，**按邻接表中存储的顺序**遍历当前节点的邻居，若邻居未访问则递归调用该函数。
- **唯一性：** 在邻接表顺序固定的情况下，这两种算法的遍历顺序是唯一确定的。

**输入格式：**

1. 第一行：一个整数 $N$（节点数）。
2. 第二行：$N$ 个数字的排列，表示 BFS 访问顺序。
3. 第三行：$N$ 个数字的排列，表示 DFS 访问顺序。

**输出格式：**

- 若无解，输出 `-1`。
- 若有解，第一行输出边数 $M$（$M \le 10^5$），随后 $M$ 行每行输出一条边 `a b`。

## 解题思路

**核心思考**

- 题目要求构造同时符合**BFS和DFS数列搜索顺序**的图，同时题目给出会**按邻接表顺序遍历**这个关键信息
- 从**构建adj**出发，按dfs数列顺序建造基础adj，再往**顶点1的adj**添加符合bfs遍历顺序的其他vertices

## 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> bfs(n);
    vector<int> dfs(n);
    for (int i = 0; i < n; i++) cin >> bfs[i];
    for (int i = 0; i < n; i++) cin >> dfs[i];

    vector<pair<int, int>> ans;
    
    for (int i = 1; i < n; i++) {
        ans.push_back({dfs[i - 1], dfs[i]});
    }

    for (int i = 2; i < n; i++) {
        ans.push_back({1, bfs[i]});
    }
    cout << ans.size() << '\n';
    for (auto x : ans) {
        cout << x.first << ' ' << x.second << '\n';
    }

    return 0;
}
```
