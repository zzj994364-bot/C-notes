## 向上取整(ceiling)

### 本质（Nature）

向上取整的数学本质是寻找大于或等于给定实数的最小整数。

在数学符号中，通常用 $\lceil x \rceil$ 表示（称为 Ceiling 符号）。

- **定义**：对于任意实数 $x$，$\lceil x \rceil = n$，其中 $n$ 是满足 $n \ge x$ 的最小整数。
- **数轴直观理解**：在水平数轴上，向上取整就是向**右**侧寻找最近的整数点（如果本身是整数则保持不变）。
- **与向下取整的区别**：
  - 向下取整（Floor, $\lfloor x \rfloor$）：向左找最大整数。
  - 向上取整（Ceiling, $\lceil x \rceil$）：向右找最小整数。

------

### 目的（Purpose）

在编程和逻辑设计中，向上取整的核心目的是**“确保覆盖”**或**“不留余数”**。

- **资源足额分配**：当资源不能分割时（如人、车、箱子），即使剩余部分不到 1 个单位，也必须分配 1 个完整的单位来承载。
- **边界处理**：确保计算结果在满足最小需求的前提下，向上触达下一个完整的层级。
- **消除余数影响**：在除法运算中，只要存在余数，就判定为需要额外的一个计数单位。

------

### 代码实现（Implementation）

#### A. 标准库函数

通常使用 `ceil()` 函数。

C++

```
double res = ceil(3.14); // 结果为 4.0
double res2 = ceil(-3.14); // 结果为 -3.0
```

#### B. 整数除法技巧（竞赛常用）

在处理正整数除法 $a / b$ 时，为了避免浮点数精度误差，常用以下公式实现向上取整：

$$\lceil \frac{a}{b} \rceil = \frac{a + b - 1}{b}$$

```cpp
#include <iostream>

int main() {
    // 示例 1：不能整除的情况
    int a1 = 10, b1 = 3;
    int res1 = (a1 + b1 - 1) / b1; 
    // 运算过程：(10 + 3 - 1) / 3 = 12 / 3 = 4

    // 示例 2：能够整除的情况
    int a2 = 12, b2 = 3;
    int res2 = (a2 + b2 - 1) / b2;
    // 运算过程：(12 + 3 - 1) / 3 = 14 / 3 = 4 (整数除法丢弃余数)

    // 示例 3：实际应用（分页计算）
    int totalItems = 101;
    int pageSize = 10;
    int totalPages = (totalItems + pageSize - 1) / pageSize;
    std::cout << "101条数据，每页10条，总页数: " << totalPages << std::endl;

    return 0;
}
```

- **逻辑证明**：
  - 如果 $a$ 能被 $b$ 整除，则 $b-1$ 不足以产生进位。
  - 如果 $a$ 不能被 $b$ 整除，则余数至少为 $1$，加上 $b-1$ 后必然会向商进 $1$ 位。

------

### 具体应用例子（Applications）

#### 场景一：分页系统（Pagination）

这是 Web 开发中最常见的例子。已知总记录数 `total` 和每页显示条数 `pageSize`，求总页数。

- **公式**：`totalPages = (total + pageSize - 1) / pageSize`
- **实例**：101 条数据，每页 10 条。$101 / 10 = 10.1$，必须向上取整为 11 页，否则最后 1 条数据无法显示。

#### 场景二：容器装载（Batch Processing）

假设有 $N$ 个货物，一辆货车一次最多运 $K$ 个，求最少运送次数。

- **实例**：有 7 个学生，一辆出租车限坐 4 人。虽然 $7/4 = 1.75$，但你必须叫 2 辆车。

#### 场景三：内存对齐（Memory Alignment）

在计算机底层，内存通常按 4 字节或 8 字节对齐。如果申请 13 字节空间，系统实际会分配 16 字节。

- **目的**：提高 CPU 访问内存的效率。

#### 场景四：时间调度

如果一个任务每 5 分钟执行一次，现在过了 7 分钟，求任务已经进入了第几个周期。

- **计算**：$\lceil 7 / 5 \rceil = 2$，即任务正在进行第 2 个周期。

------

### 常见误区

- **负数处理**：$\lceil -3.1 \rceil$ 是 $-3$ 而不是 $-4$。因为 $-3$ 是大于 $-3.1$ 的最小整数。
- **浮点精度**：在 C++ 中使用 `ceil(a/b)` 时，如果 $a$ 和 $b$ 都是 `int`，`a/b` 会先进行整数除法（丢弃余数）。必须写成 `ceil((double)a/b)`。
