# 广度优先搜索 (Breadth First Search)

**心得**

- 本质是利用**queue先进先出**的特质维护**广度优先**
- 代码实现的主循环是检查**q.empty()**
- 对当前node的处理是**在node被弹出q后的区域**
- 不具备**回溯影响父节点**的功能，通常要使用**全局变量**
- 通常在**访问邻居**时，进行**对父节点的记录**

## 基础

广度优先搜索（Breadth First Search, BFS）是另一种用于遍历或搜索树或图的算法。与深度优先搜索（DFS）的“一路到底”策略不同，BFS 从一个起始顶点出发，首先访问其所有直接相邻的邻居，然后逐层向外扩展，访问第二层、第三层的邻居，以此类推。BFS 遵循“逐层扩散”的策略。

BFS 的实现是**迭代**的，其核心数据结构是一个**队列（Queue）**，用于维护待访问的节点顺序，保证了先进先出的逐层访问次序。

**解决的问题与应用**:
BFS 的“逐层”特性使其特别适用于解决最短路径相关的问题。

  * **无权图最短路径 (Shortest Path in Unweighted Graphs)**: 这是 BFS 最核心和最强大的应用。从起点 `s` 开始执行 BFS，第一次到达任意节点 `v` 时所经过的路径，一定是 `s` 到 `v` 的边数最少的路径。
  * **层序遍历 (Level Order Traversal)**: BFS 的执行过程天然地构成了对图或树的层序遍历。
  * **状态空间搜索**: 在许多问题中，可以将问题抽象成一个状态图，BFS 可以用来找到从初始状态到目标状态的最少转换次数。例如：最少步数解迷宫、魔方复原、8-puzzle 问题等。
  * **二分图判定 (Bipartite Graph Check)**: 可以使用 BFS 对图进行“染色”。从一个节点开始染成颜色1，其所有邻居染成颜色2，再将邻居的邻居染成颜色1，以此类推。如果在染色过程中发现一个邻居已经被染成了和当前节点相同的颜色，则该图不是二分图。
  * **寻找连通分量**: 和 DFS 一样，BFS 也可以用来遍历图中的所有节点，从而找到各个连通分量。

时间/空间复杂度（使用邻接表表示图）：

  * **时间复杂度**: $O(V+E)$。其中 $V$ 是顶点数，$E$ 是边数。每个顶点和每条边都只会被访问一次。
  * **空间复杂度**: $O(V)$。主要空间开销来自 `visited` 数组和队列。在最坏的情况下（例如，一个星形图），队列中可能需要存储近 $V$ 个顶点。

## 算法的流程

1.  **初始化**:
    a. 创建一个**队列 (Queue)**，并将起始顶点 `s` 入队。
    b. 创建一个 `visited` 数组（或哈希表），并将 `s` 标记为已访问。
    c. （可选）创建一个 `distance` 数组来记录距离，`distance[s]` 初始化为 0。
2.  **主循环**: 当队列不为空时，持续执行循环。
3.  **出队**: 从队列头部取出一个顶点 `u`。
4.  **处理当前节点**: 对顶点 `u` 执行所需的操作。
5.  **探索邻居**: 遍历 `u` 的所有邻居 `v`。
6.  **检查并入队**: 对于每个邻居 `v`，如果它**尚未被访问**：
    a. 将 `v` 标记为已访问。
    b. （可选）更新 `v` 的信息，例如 `distance[v] = distance[u] + 1`。
    c. 将 `v` 加入队列尾部。
7.  **结束**: 当队列为空时，表示所有从 `s` 可达的顶点都已被访问，算法结束。

## 算法模板

从单个源点开始，对图的一个连通分量进行广度优先遍历。

```cpp
#include <vector>
#include <queue>

const int MAXN = 100005;

vector<int> adj[MAXN];    // 邻接表
bool visited[MAXN];      // 访问标记数组
int n;                   // 顶点数

/**
 * @brief 从 start_node 开始执行一次 BFS
 * @param start_node 起始顶点
 */
void bfs(int start_node) {
    // 1. 初始化
    queue<int> q;
    q.push(start_node);
    visited[start_node] = true;

    // 2. 主循环
    while (!q.empty()) {
        // 3. 出队
        int u = q.front();
        q.pop();

        // 4. 在这里处理当前节点 u
        // process(u);

        // 5. 探索邻居
        for (int v : adj[u]) {
            // 6. 如果邻居 v 未被访问
            if (!visited[v]) {
                visited[v] = true;
                q.push(v);
            }
        }
    }
}
```
