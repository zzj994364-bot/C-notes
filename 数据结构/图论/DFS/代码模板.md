# DFS题思考流程

- 如何**构造要求的图**（环？树？）

  - 邻接表是按**点**构造还是按**边**构造

    ```cpp
    vector<vector<int>> adj;
    //或者
    struct edge {
        int to;
        int weight;
    }
    vector<vector<edge>> adj;
    ```

- 题目的本质是求**图的什么属性**

- 确定**变量类型**

  - **全局**变量

  - **函数参数**

  - ```cpp
    //返回值
    int dfs() {
    }
    ```

- **DFS**遍历实现

  - 标记访问：将当前顶点 `u` 标记为已访问。
  - 处理当前节点
  - 继续传递
  - 探索邻居并调用递归
  - 返回: 当 `u` 的所有邻居都已被探索完毕，函数返回，程序回溯到调用 `dfs(u)` 的地方。





## 基础模板

```cpp
//adjacency list
vector<vector<int>> adj;
//visited
vector<bool> visited;

void dfs(int u) {
    visited[u] = true;
    
    /* ======================
          处理当前节点的内容
       ====================== */

    //遍历邻居节点
    for (auto v : adj[u]) {
        if (!visited[v]) { //状态检查，防止死循环
            
            dfs(v);        //递
            --------       
            
        }
    }
    /* ==========
       “归”后的处理
       ========== */
}
```

## 按边DFS

一旦题目出现下面任何一个关键词，普通**按点 DFS** 就会**失效**：

- **“每条边都要处理”**
- **“回边 / 环 / 重边”**
- **“边有权值 / 方向 / 状态”**
- **“必须走完整个环”**

```cpp
struct directed_edge{
    int to;
    int cost;
};

//directed edge adj
vector<vector<directed_edge>> adj;
long long ans;

void dfs(int to, int from, int cost) {
    if (to == 1) {
        ans = cost;
        return;
    }
    for (auto e : adj[to]) {
        if (e.to != from) {
            dfs(e.to, to, cost + e.cost);
        }
    }
}

```

## 子树大小（有根的树）

```cpp
int sz[MAXN];
void dfs(int u, int fa) {
    sz[u] = 1; // 自身计 1
    for (int v : adj[u]) {
        if (v == fa) continue; // 状态检查：当下个节点是父节点，跳过
        dfs(v, u);
        sz[u] += sz[v]; // 累加子树的结果
    }
}
/* =================================
   dfs(1, 0)计算1的子树大小
   因为1是根节点，所以fa = 0代表没有父节点
   ================================= */
```



## ”树“中某一节点能达到的最大路径（无相有权图）

```cpp
struct edge {
    int to;
    int cost;
};
vector<vector<edge>> adj;
vector<bool> visited;
// 返回从节点u出发，能达到的最大路径代价
int dfs(int u) {
    visited[u] = true;
    int max_depth = 0; // ← 每次调用都创建新的变量,每个节点的 max_depth 都是独立的。
    
    for (auto e : adj[u]) {
        if (!visited[e.to]) {
            
            int child_depth = dfs(e.to); // ← 递归调用
            max_depth = max(max_depth, e.cost + child_depth);
 
        }
    }
    return max_depth; // ← 返回当前层的max_depth
}
```
