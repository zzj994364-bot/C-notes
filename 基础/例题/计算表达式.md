##  I: 计算表达式

**内存限制：32 MB****时间限制：1.000 S**

**评测方式：文本比较****命题人：外部导入**

**提交：46****解决：5**

#### 题目描述

计算表达式的值。表达式计算符号只包含加（+）、减（-）、乘（*）、除（/），不含括号，参与计算的数值都是整数。

#### 输入

存在多种数据，每组数据一行，表达式不存在空格

#### 输出

输出结果

#### 样例输入 复制

```plain
6/2+3+3*4
734/2-56*2-7*8
```

#### 样例输出 复制

```plain
18
199
```









































## 解题思路

- string读取一行
- 创建一个**加减法**数组
- 遍历s，遇到乘除时对数组末尾进行乘除运算；遇到加减直接push进数组

## 代码实现

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

        /*
        遇到乘除时直接对数组最后一位进行运算
        遇到加减则push进数组，放到最后算进res
        */

int main() {
    string s;
    while (cin >> s) {
        vector<int> num;
        string temp;

        //op存放的是遇到的符号前一个运算符号，第一个数字当加法处理
        char op = '+';
        /*
        当遇到符号的时候才会对前面一个数字进行处理再更新符号
        所以需要在末尾多添加一个符号
        */
        s += '+'; //末尾随意添加一个符号，使最后一个数能结算
        for (int i = 0; i < s.size(); i++) {
            char ch = s[i];
            if (isdigit(ch)) temp += ch;
            else if (ch == '+' || ch == '-' || ch == '*' || ch == '/') {
                int cur_num = stoi(temp);
                if (op == '+') num.push_back(cur_num);
                if (op == '-') num.push_back(-cur_num);
                if (op == '/') num.back() /= cur_num;
                if (op == '*') num.back() *= cur_num;
                temp.clear();
                op = ch;
            }
        }
        int res = 0;
        for (auto n : num) {
            res += n;
        }
        cout << res << '\n';
    }
    return 0;
}
```
