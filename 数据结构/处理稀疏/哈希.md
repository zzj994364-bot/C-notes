# 哈希表处理

**思考**

- **map**可以看作一个**index不受限**的数组
- **map**的下标**不需要从头开始扩展**
- **map**天然适合处理**稀疏**的结构
- **map**基于**红黑树有序O(longn)**
- **unordered_map**基于**哈希表无序O(1)**

## 一、问题特征

### 1.1 什么是稀疏网格问题？

- **坐标范围极大**：坐标可能达到 10^9 甚至 10^18
- **有效点数量少**：虽然范围大，但实际可访问的点很少（≤ 10^5）
- **无法开大数组**：直接用二维数组会 MLE（内存超限）

### 1.2 常见题型

- 大坐标范围的网格路径问题
- 稀疏图的 BFS/DFS
- 只给出部分可访问格子的问题
- 线段覆盖 + 最短路径

## 二、两种处理思路

### 2.1 方法对比

| 方法                    | 核心思想                     | 实现方式                       | 适用场景         |
| ----------------------- | ---------------------------- | ------------------------------ | ---------------- |
| **直接用 map 存储状态** | 把坐标作为 key 直接存入 map  | `map<pair<int,int>, 状态>`     | 简单直接，代码短 |
| **坐标压缩 + 编号**     | 先映射坐标到小编号，再用数组 | `map<坐标, 编号>` + `vector<>` | 需要频繁访问邻居 |

### 2.2 本笔记重点：直接用 map 存储（推荐方法）

**为什么推荐？**

- ✅ 代码简洁，易于理解
- ✅ 不需要额外的编号映射
- ✅ 状态和坐标绑定在一起
- ✅ 适合大部分竞赛场景

## 三、核心实现模式

### 3.1 基本模板

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 1. 使用 map 存储有效点
    map<pair<int, int>, bool> valid;
    
    // 2. 使用 map 存储访问状态/距离
    map<pair<int, int>, int> dist;
    
    // 3. 标记有效点
    for (每个有效点) {
        valid[{x, y}] = true;
    }
    
    // 4. BFS/DFS 等算法
    queue<pair<int, int>> q;
    q.push(起点);
    dist[起点] = 0;
    
    while (!q.empty()) {
        auto cur = q.front();
        q.pop();
        
        for (每个方向) {
            pair<int, int> next = {new_x, new_y};
            // 关键：同时检查 valid 和 dist
            if (valid[next] && !dist.count(next)) {
                dist[next] = dist[cur] + 1;
                q.push(next);
            }
        }
    }
}
```

### 3.2 完整示例：八方向移动的 BFS

```cpp
#include <bits/stdc++.h>
using namespace std;

// 八个方向：上下左右 + 四个对角线
int dr[] = {1, -1, 0, 0, 1, 1, -1, -1};
int dc[] = {0, 0, 1, -1, 1, -1, -1, 1};

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int x0, y0, x1, y1;
    cin >> x0 >> y0 >> x1 >> y1;
    
    // 方法1：直接用 map 存储
    map<pair<int, int>, int> dist;      // 距离
    map<pair<int, int>, bool> valid;    // 是否可访问
    
    // 读入有效线段
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        int r, a, b;
        cin >> r >> a >> b;
        // 标记这一行从 a 到 b 的所有点为有效
        for (int col = a; col <= b; col++) {
            valid[{r, col}] = true;
        }
    }
    
    // BFS
    queue<pair<int, int>> q;
    q.push({x0, y0});
    dist[{x0, y0}] = 0;
    
    while (!q.empty()) {
        auto [x, y] = q.front();
        q.pop();
        
        // 到达终点
        if (x == x1 && y == y1) {
            cout << dist[{x, y}] << endl;
            return 0;
        }
        
        // 尝试八个方向
        for (int i = 0; i < 8; i++) {
            int nx = x + dr[i];
            int ny = y + dc[i];
            pair<int, int> next_pos = {nx, ny};
            
            // 关键判断：有效 且 未访问过
            if (valid[next_pos] && !dist.count(next_pos)) {
                dist[next_pos] = dist[{x, y}] + 1;
                q.push(next_pos);
            }
        }
    }
    
    // 无法到达
    cout << -1 << endl;
    return 0;
}
```

## 四、关键技巧详解

### 4.1 用 map 的 count() 判断是否访问过

```cpp
// 方法1：使用 count()（推荐）
if (!dist.count(next_pos)) {
    // 未访问过
}

// 方法2：使用单独的 visited
map<pair<int, int>, bool> visited;
if (!visited[next_pos]) {
    // 但这会自动插入 false，占用内存
}

// 方法3：使用 find()
if (dist.find(next_pos) == dist.end()) {
    // 未访问过
}
```

**推荐用 count()**：

- 不会自动插入元素
- 代码简洁
- 效率高

### 4.2 valid 的使用

```cpp
// 错误写法：这会自动插入 false
if (valid[{x, y}]) { ... }

// 正确写法1：提前标记所有有效点
for (每个有效点) {
    valid[{x, y}] = true;
}
// 之后直接用
if (valid[{x, y}]) { ... }

// 正确写法2：使用 count()
if (valid.count({x, y})) { ... }
```

### 4.3 方向数组技巧

```cpp
// 四方向（上下左右）
int dr[] = {-1, 1, 0, 0};
```

## 五、常见变体

### 5.1 需要记录路径

```cpp
map<pair<int, int>, pair<int, int>> parent;  // 记录父节点

// BFS 中
parent[next_pos] = {x, y};

// 重建路径
vector<pair<int, int>> path;
auto cur = end_pos;
while (cur != start_pos) {
    path.push_back(cur);
    cur = parent[cur];
}
path.push_back(start_pos);
reverse(path.begin(), path.end());
```

### 5.2 带权重的最短路径（Dijkstra）

```cpp
map<pair<int, int>, int> dist;
priority_queue<pair<int, pair<int, int>>, 
               vector<pair<int, pair<int, int>>>,
               greater<>> pq;

pq.push({0, start_pos});
dist[start_pos] = 0;

while (!pq.empty()) {
    auto [d, pos] = pq.top();
    pq.pop();
    
    if (d > dist[pos]) continue;  // 已被更新过
    
    for (每个邻居) {
        int new_dist = d + 边权;
        if (!dist.count(next) || new_dist < dist[next]) {
            dist[next] = new_dist;
            pq.push({new_dist, next});
        }
    }
}
```

### 5.3 双向 BFS

```cpp
map<pair<int, int>, int> dist1, dist2;
queue<pair<int, int>> q1, q2;

// 从两端同时搜索
while (!q1.empty() || !q2.empty()) {
    // 扩展较小的队列
    if (q1.size() <= q2.size()) {
        expand(q1, dist1, dist2);  // 扩展时检查是否相遇
    } else {
        expand(q2, dist2, dist1);
    }
}
```

## 六、优化技巧

### 6.1 unordered_map 加速（需要自定义哈希）

```cpp
struct PairHash {
    size_t operator()(const pair<int, int>& p) const {
        return hash<long long>()(((long long)p.first << 32) | 
                                 (unsigned int)p.second);
    }
};

unordered_map<pair<int, int>, int, PairHash> dist;
unordered_map<pair<int, int>, bool, PairHash> valid;
```

**效果**：

- map: O(log n) 查找
- unordered_map: O(1) 平均查找
- 大数据量时提速明显

### 6.2 读入优化（线段批量标记）

```cpp
// 如果给定的是连续线段
int n;
cin >> n;
for (int i = 0; i < n; i++) {
    int r, a, b;
    cin >> r >> a >> b;
    // 标记整行
    for (int col = a; col <= b; col++) {
        valid[{r, col}] = true;
    }
}

// 优化：如果只需要判断某点是否在线段上
vector<array<int, 3>> segments;  // {r, a, b}
// BFS 时动态判断
auto is_valid = [&](int x, int y) {
    for (auto [r, a, b] : segments) {
        if (x == r && y >= a && y <= b) return true;
    }
    return false;
};
```

### 6.3 内存优化

```cpp
// 如果只需要判断访问过，不需要距离
set<pair<int, int>> visited;  // 比 map 省内存

// 或者用 unordered_set
unordered_set<pair<int, int>, PairHash> visited;
```

## 七、复杂度分析

### 7.1 时间复杂度

假设有 n 个有效点：

| 操作         | map            | unordered_map |
| ------------ | -------------- | ------------- |
| 插入 n 个点  | O(n log n)     | O(n) 平均     |
| BFS 遍历     | O(n log n)     | O(n) 平均     |
| **总复杂度** | **O(n log n)** | **O(n)**      |

**注意**：这里的 n 是有效点数量，不是坐标范围！

### 7.2 空间复杂度

- map/unordered_map: O(n)
- n 为实际存储的点数量

**对比数组法**：

```
坐标范围 10^9 × 10^9，但只有 10^5 个有效点
- 数组：10^18 bytes = 无法实现 ❌
- map：10^5 × 常数 ≈ 几 MB ✅
```

### 8.2 常见错误

```cpp
// 错误1：忘记检查 valid
if (!dist.count(next)) {  // 只检查未访问
    // 可能访问到无效点！
}

// 正确
if (valid[next] && !dist.count(next)) {
    // 既有效又未访问
}

// 错误2：自动插入导致内存爆炸
if (!visited[{x, y}]) {  // 每次调用都会插入
    // 导致大量无效点被插入
}

// 正确
if (!visited.count({x, y})) {  // 不会插入
    visited[{x, y}] = true;
}
```

## 十、总结

### 10.1 记忆要点

✅ **稀疏网格 = 直接用 map 存储坐标**
 ✅ **用 count() 判断是否访问，避免自动插入**
 ✅ **valid 和 dist 分开存，逻辑更清晰**
 ✅ **方向数组让代码更简洁**
 ✅ **unordered_map 需要自定义哈希，但更快**

### 10.2 适用场景判断

```
坐标范围 > 10^6 且 有效点数量 < 10^6
    ↓
使用 map<pair<int,int>, 状态>
    ↓
不需要坐标压缩，直接存储即可
```

### 10.3 口诀

> **稀疏网格 map 直存，**
>  **valid 和 dist 分清。**
>  **count 判断不插入，**
>  **方向数组遍历邻。**
