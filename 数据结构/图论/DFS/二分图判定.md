## 染色法

染色法的本质是**验证图的二分性（Bipartiteness）**。

从数学角度看，它是试图将图的顶点集 $V$ 划分为两个互不相交的子集 $U$ 和 $W$，使得图中的每一条边 $(u, v)$ 所连接的两个顶点分别属于不同的集合。

- **核心逻辑**：如果你给一个点染上颜色 A，那么它的所有邻居节点**必须**染上颜色 B。
- **冲突检测**：如果在染色过程中，发现某个点的邻居已经被染成了和自己相同的颜色，这就产生了“逻辑冲突”，说明该图无法被二分。

------

### 解决什么问题？

染色法最直接的应用是解决**二分图判定**问题，但它可以延伸到很多场景：

- **二分图判定**：判断一个图是否可以只用两种颜色染色，使得相邻点颜色不同。
- **奇环检测**：一个图是二分图的充要条件是**图中不含奇环**（边数为奇数的环）。染色法是检测奇环最高效的方法。
- **二分图最大匹配的前置条件**：在做匈牙利算法或网络流匹配前，通常需要确认图是否为二分图。
- **实际应用**：比如排课系统（互斥课程不能排在同一时间）、相亲对象匹配、地图染色等。

------

### 代码模板

最常用的实现方式是 **DFS（深度优先搜索）**，因为它代码最简洁。

**注意**

- 必须考虑图是否**连通**的情况

- 一个vector在不同测试用例里的重置:

  ```cpp
  color.assign(n + 1, 0);
  ```

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
vector<int> adj(MAXN);
vector<int> color(MAXN); // 0: 未染色, 1: 颜色A, 2: 颜色B

// 返回值：true 表示染色成功（是二分图），false 表示有冲突（非二分图）
bool dfs(int u, int c) {
    color[u] = c; // 给当前点染色
    
    for (int v : adj[u]) {
        if (color[v] == c) return false; // 发现邻居颜色一样，冲突！
        
        if (color[v] == 0) { // 邻居未染色
            if (!dfs(v, 3 - c)) return false; // 给邻居染相反色，若后续返回假，则整体为假
        }
    }
    return true;
}

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v; cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    bool isBipartite = true;
    for (int i = 1; i <= n; i++) {
        if (color[i] == 0) { // 处理不连通图的情况
            if (!dfs(i, 1)) {
                isBipartite = false;
                break;
            }
        }
    }

    if (isBipartite) cout << "YES" << endl;
    else cout << "NO" << endl;

    return 0;
}
```
