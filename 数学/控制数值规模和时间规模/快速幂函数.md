## 算法模板

### 模板一：普通快速幂

用于计算 $a^n$，不涉及取模。注意当 `a` 和 `n` 较大时，结果会迅速超出 `long long` 的范围。

```cpp
/**
 * @brief 普通快速幂，计算 base^exp
 * @param base 底数
 * @param exp 指数
 * @return base^exp 的结果
 */
long long power(long long base, long long exp) {
    long long res = 1;
    while (exp > 0) {
        // 如果指数的当前二进制位是 1
        if (exp & 1) {
            res *= base;
        }
        // 底数平方，为下一位做准备
        base *= base;
        // 指数右移一位
        exp >>= 1;
    }
    return res;
}
```

### 模板二：快速幂取模

这是最常用、最重要的版本，用于计算 $(base^{exp}) \pmod{mod}$。

```cpp
/**
 * @brief 快速幂取模，计算 (base^exp) % mod
 * @param base 底数
 * @param exp 指数
 * @param mod 模数
 * @return (base^exp) % mod 的结果
 */
long long power_mod(long long base, long long exp, long long mod) {
    long long res = 1;
    // 预处理底数，使其在 [0, mod-1] 范围内
    base %= mod;
    while (exp > 0) {
        // 如果指数的当前二进制位是 1，则将当前 base 乘入结果
        if (exp & 1) {
            res = (res * base) % mod;
        }
        // 底数平方，为处理指数的下一位做准备
        base = (base * base) % mod;
        // 指数右移一位，处理下一位
        exp >>= 1;
    }
    return res;
}
```

## 函数作用：计算

```
(base^exp) mod mod
```

------

### 🔹 1. base 是什么？

**base = 底数**

在表达式 `a^b mod m` 中的：

- `a` 就是 **base**

例子：

```
3^13 mod 1000000007
base = 3
```

------

### 🔹 2. exp 是什么？

**exp = 指数 exponent**

在 `a^b mod m` 中的：

- `b` 就是 **exp**

例子：

```
3^13 mod 1000000007
exp = 13
```

------

### 🔹 3. mod 是什么？

**mod = 取模的模数**

在 `a^b mod m` 中的：

- `m` 就是 **mod**

常见模数：

- `1e9+7`
- `998244353`
- 或者任意你给的整数

例子：

```
3^13 mod 1000000007
mod = 1000000007
```

------

### 🔹 4. return result 是什么？

**它返回的就是：**

```
(base^exp) % mod
```

也就是 **幂运算之后再取模的结果**。

------

###  一个完整例子

调用：

```
power(3, 13, 1000000007);
```

函数返回：

```
1594323
```

因为：

```
3^13 = 1594323
1594323 mod 1000000007 = 1594323
```

------

###  再举一个大数的例子

```
power(2, 1000000000000LL, 1000000007);
```

函数返回的是：

```
2^1000000000000 mod 1000000007
```

这个值正常用计算机要做一万亿次乘法，而快速幂只需要 **log₂(1e12) ≈ 40 次循环**。
